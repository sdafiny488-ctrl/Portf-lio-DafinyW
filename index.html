HTML

O HTML é a linguagem base de toda a internet. É através dele que qualquer página web é construída, funcionando como a estrutura física, os alicerces e o esqueleto de um site.

ʚ⠀ິɞ

CSS

O CSS é a linguagem padrão da web utilizada para definir a aparência estética e o layout de páginas de internet. Ele não é uma linguagem de programação, mas sim uma linguagem de folhas de estilo que dita como os elementos estruturados em um arquivo HTML devem ser apresentados visualmente para o usuário.

{ }

JavaScript

O JavaScript é a linguagem de programação que dá vida à internet. Enquanto o HTML constrói a estrutura e o CSS define o visual, o JavaScript é o motor que introduz dinamismo, interatividade e lógica às páginas web.
